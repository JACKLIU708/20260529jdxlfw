# V1.0 演示成交版执行说明

## 定位

前期面向演示成交，采用“强 UI 呈现 + 真闭环流程 + 正式化数据结构预留”的策略。系统当前为可离线打开的前端演示版，业务文案、页面结构、角色权限、安全边界和 AI 报告流程均按正式产品口径设计。

## 功能范围

- 领导驾驶舱：风险态势、重点关注、未闭环任务、服务完成率、热力图、AI 报告入口。
- 组织人员：单位层级、人员导入、角色绑定、标准编码。
- 测评导入：Excel 导入演示、风险初筛、原始文件归档。
- 重点台账：风险等级、来源、责任人、状态、闭环进度、脱敏编码。
- 随访任务：待派单、执行中、待复核、已闭环。
- 危机干预：事件登记、研判复核、处置记录、转介/上报、复盘报告。
- 服务台账：咨询、团辅、热线、巡诊、讲座、满意度。
- AI 报告：月报、危机报告、访谈报告、巡诊总结，支持人工确认与水印导出模拟。
- 审计备份：访问日志、导出日志、备份包、同步默认关闭。

## 推荐 AI 模型

主推阿里通义千问 Qwen 系列。演示版先做本地模板模拟，后续真实接入时增加模型适配层。

- 高质量报告生成：Qwen3-Max / Qwen3-Max-Thinking。
- 高频摘要与材料整理：Qwen3.5-Plus。
- 备选：DeepSeek 用于推理增强，Kimi 用于长文档处理，智谱 GLM 用于国产化政企备选。

## 演示脚本

1. 登录并说明单机部署、本地运行、默认不上报。
2. 打开领导驾驶舱，展示风险态势、未闭环事项和服务完成率。
3. 进入测评导入，模拟 Excel 导入和风险初筛。
4. 进入重点台账，说明系统只提示风险，最终等级需人工复核。
5. 创建随访任务，展示责任人、周期、完成进度和复核状态。
6. 打开危机干预闭环，展示从登记到复盘报告的全过程留痕。
7. 进入 AI 报告中心，生成月度报告草稿并人工确认。
8. 导出带水印报告，回到审计备份查看留痕。
9. 收尾强调 V1.0 单机闭环，未来可升级局域网和总控接入。
